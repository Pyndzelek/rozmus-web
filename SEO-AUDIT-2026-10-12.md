# SEO audit of filiprozmus.pl: health score 55/100

Date: 2026-10-12. Business type: local service (personal trainer, Nowy Targ).

Eleven specialist audits ran: technical, content, schema, sitemap, performance, AI search (GEO), agent readiness, local, search experience (SXO), backlinks, and Google data. The most important claims were checked against the live site and the code. Where an auditor was wrong, the plan below corrects it.

| Content quality | 23% | 38 |

| Structured data (schema) | 10% | 48 |

Other scores: Local SEO 38/100, SXO gap 44/100. Backlinks: not enough data for a score.

The code is in good shape: pages are rendered on the server, nothing is blocked from indexing, layout shift is negligible and desktop speed is 99–100. The score is held back by three things: the site points search engines at a host it doesn't actually use, it has very little text Google can read, and Filip barely exists as a local business outside the site.

## Critical: fix this week

### 1. Every URL the site declares uses `www`, but the live site is at `filiprozmus.pl`

- `www.filiprozmus.pl` redirects (301) to `filiprozmus.pl`. Yet the sitemap, robots.txt, OpenGraph tags and structured data all list `www` addresses, so all 10 sitemap URLs are redirects.
- No page has a canonical tag. `Pricing-oferta.tsx` uses the apex domain, which makes things even more mixed.
- **Fix:**
  - In `next-sitemap.config.js`, set `siteUrl` to `https://filiprozmus.pl`.
  - In `src/app/layout.tsx`, change all `www` URLs, add `metadataBase: new URL("https://filiprozmus.pl")` and add `alternates.canonical`.
  - Rebuild so the committed `public/sitemap*.xml` and `public/robots.txt` regenerate.
  - Update the site URL in CLAUDE.md as well.
- **How to check it worked:** every URL in `/sitemap.xml` returns 200, not 301, and each page has a canonical tag pointing to itself.
- **Note:** the local SEO and backlinks audits got the redirect direction backwards and suggested linking to `www`. Ignore that.

### 2. The site contradicts itself

- **Opening hours:** the structured data in `src/app/layout.tsx` says Saturday 9:00–22:00, but `src/components/kontakt/KontaktInfo-kontakt.tsx:31` says Saturday 9:00–15:00.
- **Free consultation:** the `/kontakt` text, its meta description and the homepage description still promise one ("bezpłatna konsultacja"), but it was removed from the offer in commit 0ff45bc.
- **Diet consultations:** the `/oferta` meta description promises "konsultacje dietetyczne", but the FAQ says Filip doesn't write meal plans ("nie rozpisuję konkretnych jadłospisów").

### 3. No Google Business Profile is visible anywhere

- There's no Maps embed, no review link, and the profile isn't in `sameAs`.
- In the searches the auditors could run, `filiprozmus.pl` didn't show up at all, even for the name. The only local result was Studio Gorce's Fresha listing at the same address (Al. Tysiąclecia 74).
- Results for "trener personalny Nowy Targ" are won mainly through Google Maps, so this is the biggest growth lever.
- **Fix:**
  - Claim and fill out the profile. Category "Trener osobisty"; hours, photos and services matching the site.
  - Add a Maps embed and a "Dodaj opinię" link to `/kontakt`, and add the profile URL to `sameAs`.
  - Ask Studio Gorce to name Filip and link to the site.

## High: within 2 weeks

4. **Google sees "0 +" and "0 %" for the homepage stats.** The count-up only sets the real numbers in the browser. Put the real numbers in the server HTML and keep the animation on top.
5. **FAQ answers aren't in the HTML.** `src/components/faq-section.tsx:82` adds them only when clicked (AnimatePresence), so crawlers see only the questions. Render them hidden but present, for example with `<details>`. Useful questions to add:
   - "Ile kosztuje trening personalny w Nowym Targu?"
   - "Gdzie odbywają się treningi?"
   - "Jak wygląda pierwszy trening?"
6. **The reviews on `/opinie` are 16 screenshots with about 25 words of text.** Type out 6–10 reviews as text: first name, town, service, result. Don't add Review or AggregateRating markup for these; Google treats self-hosted reviews as self-promotional and won't show them.
7. **`/oferta` loads slowly on mobile (LCP 4.8 s).** The heading in `src/components/oferta/Hero-oferta.tsx:10-12` starts invisible (`opacity: 0`) and fades in only after the JavaScript loads. Remove that fade-in on the hero. Expect LCP of about 2 s and a mobile score above 95.
8. **`/formularz` has no title or description of its own and no H1.**
   - It's a client-side page (`"use client"`), so it can't define metadata, and it reuses the homepage title and description.
   - Split it into a server `page.tsx` with metadata plus a client form component.
   - Add `robots: { index: false, follow: true }` and an H1, and remove the page from the sitemap.
9. **Sitemap and robots.txt cleanup.**
   - The sitemap lists files that aren't pages: `apple-icon.png`, `icon0.svg`, `icon1.png` and `manifest.json`. Exclude them, along with `/formularz`.
   - Drop `changefreq` and `priority`; Google ignores both.
   - Remove the `Host:` line from robots.txt; only Yandex uses it.
10. **The homepage H1 has no keyword or city.** Change "Zrób sylwetkę, której nikt nie przegapi" to something like "Trener personalny Nowy Targ – Filip Rozmus", with the current slogan as a subheading.

## Medium: within a month

11. **Structured data:**
    - Replace the single `LocalBusiness` block with a connected `@graph`: WebSite, the business (`#business`) and a Person entity for Filip (`#filip`).
    - Use the correct hours: Mon–Fri 9:00–22:00 and Sat 9:00–15:00, as two separate entries.
    - Write the phone in international format as `+48513978894`.
    - Set a real price range of 150–2000 zł. `Pricing-oferta.tsx:127` currently reads the 4th plan and shows 1800 zł as the maximum.
    - In `Pricing-oferta.tsx:139`, change `logo_nlt_czarne.jpg` to `.png`. The `.jpg` file doesn't exist.
    - In `Pricing-oferta.tsx:180`, replace `<Script>` with a plain `<script>` so the data is in the server HTML.
12. **Thin pages:**
    - `/o-mnie` has about 90 words. Name the certificate issuers and years, the year of the WRPF title, and the lifts. Aim for 500+ words.
    - `/oferta` needs around 150 words per package: who it's for and how sessions run.
    - Add a service-area section, for example: "Treningi stacjonarne prowadzę w Studio Gorce w Nowym Targu – trenują u mnie osoby z Szaflar, Ludźmierza, Czarnego Dunajca…". Use a section, not separate pages per town, which Google treats as doorway pages.
13. **New page `/trener-personalny-online`.** That search is national and rewards dedicated pages; right now online coaching is just one 200 zł card. Cover the process (form → plan → weekly reports → technique check), the price, results and an FAQ.
14. **Lost leads:**
    - 4 of the 7 plans link to `/kontakt` without passing the chosen plan. Use `/kontakt?plan=…`.
    - The survey has about 14 required fields before any contact details are collected. Ask for contact details first and move the questionnaire to a second step.
    - Plan slugs depend on `createPlanSlug` (e.g. `12-treningw--plan`). Use the plan `id` instead so they don't break easily.
15. **Business directories:** Bing Places, Apple Business Connect, Panorama Firm, pkt.pl, a Facebook business page and Booksy/Fresha. Use exactly the same name, address and phone everywhere, and one canonical Facebook URL.

## Low: backlog

- **Accessibility:** three unlabeled controls (the weight slider and a dropdown in `calorie-calculator.tsx`, the Instagram icon link in the footer). `<main>` is used only on `/formularz`. The radio and checkbox groups in the calculator and survey have no group labels.
- **404 page:** no custom one. Add `src/app/not-found.tsx` with links and Polish copy.
- **Security headers:** only HSTS is set. Add `headers()` in `next.config.js` for X-Content-Type-Options, Referrer-Policy and frame-ancestors.
- **Viewport:** `viewport` sits inside `metadata`, which is deprecated in Next 14. Make it its own export.
- **Analytics:** load Google Analytics with `lazyOnload` (179 KB).
- **Images:** compress the homepage hero PNG `/rozmus_nlt.png` (about 320 KB can be saved) and enable AVIF/WebP. Fix the one English alt text ("Personal trainer") and the generic transformation alt texts.
- **Animations and bundle:** animate the progress bar with `scaleX` instead of width. Consider `LazyMotion` for framer-motion.
- **Contact form:** add `autocomplete` attributes.
- **Optional AI extras:** `llms.txt` and a Content-Signal line in robots.txt. Google ignores both.

## What couldn't be checked

- **Search Console:** the service account `claude-seo@kampery-seo.iam.gserviceaccount.com` got "access denied" on all three properties. To get rankings, indexing status and which host Google treats as canonical, add it under Settings → Users and permissions, preferably on a domain property `sc-domain:filiprozmus.pl`.
- **Real-user speed data:** Chrome doesn't have enough traffic for this site, so there's no field data, including INP.
- **Backlinks:** with only free sources, they couldn't be counted. The site isn't in the Common Crawl web graph. A free Moz key or Bing Webmaster Tools would fix that.
- **Off-site presence:** the actual Google Business Profile, directory listings and what ChatGPT or Perplexity answer weren't verified. Search engines blocked the agents with a consent page or captcha.
- **Screenshots:** none were taken, because Chromium isn't installed (`/seo setup` installs it).
